# Ayni Mesh pitch deck

`mesh-deck.js` generates `Ayni-Mesh-Pitch-Deck.pptx` with pptxgenjs (plus react-icons and sharp
for icons; run `npm install pptxgenjs react react-dom react-icons sharp` beside it, keep the logo
in `img/ayni-logo-t.png`, then `node mesh-deck.js`). The PDF here is the rendered copy.
